# Destiny Tracker

Overlay + HUD tracker for Destiny 2 raids.

## Features
- Live activity timer
- Raid completion notifications (toast)
- Overlay HUD (in-game)
- Profile system (multi accounts)

## Tech
- Tauri
- SvelteKit
- Rust

## Setup

```bash
npm install
npm run tauri dev
